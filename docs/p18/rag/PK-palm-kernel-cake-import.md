# Pakistan — Palm Kernel Cake import policy and tariff research

## Chunk ID: PK-PKE-001 — Commodity identification
TIPP identifies national tariff code 230660001000 as Palm Kernel Cake under heading 2306 and subheading 230660 (oil-cake of palm nuts or kernels). This is a Pakistan national tariff record. It is not proof of the correct Indonesian BTKI code and is not a binding classification for every PKE product.
Source: TIPP commodity record 230660001000.

## Chunk ID: PK-PKE-002 — Import policy default and restrictions
TIPP's Import Policy Order 2022 page states that imports may generally be made from worldwide sources unless a good is prohibited or restricted by the Order. The Order has been amended repeatedly; the Ministry of Commerce's SRO index lists 2026 amendments. A shipment-date decision must use the consolidated Order and all effective amendments, not the 2022 base text alone.
Sources: TIPP Import Policy Order 2022; Pakistan Ministry of Commerce SRO index.

## Chunk ID: PK-PKE-003 — Displayed tariff snapshot
The TIPP record displayed 10% customs duty (effective 1 July 2025), 18% statutory sales tax and 12% income tax. These are source snapshots, not guaranteed current landed costs. Verify tariff-year changes, exemptions, SROs, importer status and other levies with Pakistan Customs before commercial use.

## Chunk ID: PK-PKE-004 — No false restriction inference
The cited TIPP Import Policy Order text includes a restriction for certain animal-origin feed ingredients in specified BSE-risk situations. PKE is plant-derived, so that clause must not be applied to PKE by analogy. Other country-of-origin, quarantine, quality or product-specific requirements may still apply and require official confirmation.
